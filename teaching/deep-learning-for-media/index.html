Syllabus sample · Fall 2026 · 3 credits

Deep Learning for Media

MPATE-GE 2039 · DM-GY 9103

Overview

Deep learning, a sub-field of machine learning and artificial intelligence, has promoted breakthroughs in managing and creating media content, and continues to shape the future of the multimedia landscape. This course is a hands-on, project-oriented introduction to deep learning for the classification, retrieval, and creation of media, with emphasis on audio-visual content. Students create and work with existing deep learning models using Python libraries, and think critically about how those models are applied to media.

The goal of the course is to provide students with:

  • Basic knowledge of deep learning, including definitions, pipeline development, and evaluation.
  • Practical skills for working with open source deep learning resources in Python.
  • Awareness of current practice in the retrieval, classification, and creation of audio-visual content.
  • The ability to critically analyze deep learning systems in the context of media.

By the end of the course, students will be able to explain basic deep learning concepts, code deep learning pipelines with open source Python libraries, assess systems on new audio-visual data, and explain current trends in deep learning for audio and image.

Requirements

Meetings mix conversational lectures, live-coding demonstrations, and group readings. Readings follow the role-playing paper-reading format of Jacobson and Raffel: everyone reads the same paper, and each student takes one role for that week. Roles are set at the start of the course. Students coordinate a single presentation and submit their slides afterward. Papers are assigned after the drop/add deadline. A short guide on how to read a paper is part of the preparation.

There are 2 homework assignments, each with Python code and a written component. They are not graded. They prepare you for the midterm, so complete each one within about two weeks and ask about anything that is unclear. Part of the midterm is based on the homeworks.

The midterm assesses the first weeks of the semester. More detail is posted on Brightspace.

The final project is done in groups and has a code component and a presentation in the last class. The instructor defines the topics. Groups rank them, and the instructor makes the final assignment. It has three parts:

  • Progress presentation. Each group presents its progress, especially the scope, the data, and the baselines, followed by questions from the instructor.
  • Documented code. Working, documented code in a GitHub repository, plus a demo website with results and examples. The code should explain the decisions made and present a rigorous analysis. The homework structure is a useful guide.
  • Final presentation. Every member of the group presents in the last class. Presentations include slides and are followed by a short question period.
  • 30% midterm (individual)
  • 40% final project (groups)
  • 30% class participation (individual)

Schedule

  1. Week 0

    Supplementary materials

    • Python and NumPy tutorial
  2. Week 1 · Sep 8

    Introduction to machine learning

    • Course structure and schedule
    • Why deep learning, and why now
    • Frame a machine learning problem, collect a dataset, understand the data, and choose a measure of success
    • Recommended reading: Deep Learning with Python, chapters 1 and 6
    • Practice: Google Colab basics
  3. Week 2 · Sep 15

    The building blocks of neural networks

    • Scalars, vectors, matrices, tensors, and sequential data
    • Data operations
    • Practice: homework 1
    • Recommended reading: Deep Learning with Python 2.1–2.3
  4. Week 3 · Sep 22

    The engine of neural networks

    • Derivatives, derivatives of tensors, stochastic gradient descent, and backpropagation
    • Practice: gradient descent
    • Recommended reading: Deep Learning with Python 2.4
  5. Week 4 · Oct 6

    Model training and evaluation

    • Overview of deep learning for classification
    • Underfitting and overfitting, improving model fit, data augmentation, and transfer learning
    • Model biases and ethical implications
    • Practical example: homework 1
    • Recommended reading: Deep Learning with Python, chapters 4, 5, and 8
  6. Week 5 · Sep 29

    Convolutional neural networks

    • An introduction to computer vision, convolutional networks, and max-pooling
    • Practical example: homework 2
    • Recommended reading: Deep Learning with Python, chapter 8
  7. Week 6 · Oct 13

    Recap

    • Discussion of the lectures and the homeworks
    • Questions from class
  8. Week 7 · Oct 20

    Midterm exam

  9. Week 8 · Oct 27

    Cross-modal retrieval

    • Overview and applications
    • Building a cross-modal retrieval model from audio and video architectures
    • Embedding spaces and contrastive loss
    • Practical example: audio-visual cross-modal retrieval, with audio and vision encoders
  10. Week 9 · Nov 3

    Temporal convolutional networks

    • Audio manipulation, spectrograms, and temporal convolutional networks for audio
    • Audio data augmentation
    • Discussion: project assignment
    • Recommended reading: Computational Analysis of Sound Scenes and Events, chapter 4 (Brian McFee)
  11. Week 10 · Nov 10

    Project progress presentations

    • See the final project section for what to present
  12. Week 11 · Nov 17

    Transformers

    • Self-attention, transformer-based encoders, and parallels with other modalities
    • Practical example: project progress
  13. Week 12 · Nov 24

    Diffusion

    • Diffusion techniques and conditioning
    • Practical session: project progress
    • Recommended reading: Deep Learning with Python 12.5
  14. Week 13 · Dec 1

    Variational autoencoders

    • Variational autoencoders for audio generation and sampling from audio latent spaces
    • Practical session: project progress
    • Recommended reading: Deep Learning with Python 12.4
  15. Week 14 · Dec 8

    Final project presentations

    • See the final project section for what to present

Readings

Policies

Please do your part by seeking to promote the success of others, and by treating each other in ways that respect and celebrate the diversity of talent.

  • Preparation. Students come from a wide range of backgrounds. If you feel there are gaps in your knowledge, talk with me and I will help you find additional materials.
  • Classroom. Class is an open forum. Ask any question, including the ones that feel basic.
  • Accessibility. If you have accessibility requirements, present a letter from the Moses Center (212-998-4980) so materials can meet them.
  • Mental health. The NYU Wellness Exchange (212-443-9999) offers a range of services. I am available to talk about stresses related to work in this course.
  • Names and pronouns. You are welcome to use your preferred name on assignments. If your name or pronouns differ from the roster, please tell me.
  • Expenses. If obtaining any material for class is a financial hardship, tell me and I will try to arrange a loaner.
  • Feedback. I ask for anonymous feedback during the semester. Tell me if any part of the course or the class community can be improved.
  • Academic integrity. Homework is individual work. You must be able to explain anything you submit. See the NYU academic integrity statement.
  • Inclusion. NYU values an inclusive and equitable environment. If that standard is not being upheld, please speak with me.
  • Large language models. Tools such as ChatGPT and Gemini are welcome when they support learning and do not replace critical thinking. Presentations, class participation, and the midterm are assessed without them.
